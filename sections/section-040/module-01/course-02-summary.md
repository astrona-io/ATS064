# Summary

Drift is divergence between the intended managed condition and actual state. Detecting it requires an appropriate comparison scope that distinguishes authoritative fields from defaults and generated observations. Ignored differences can be deliberate but can also hide important change. Competing writers and emergency edits need explicit ownership and follow-up. A drift report identifies a state difference; it does not automatically explain its cause or prove runtime harm.
