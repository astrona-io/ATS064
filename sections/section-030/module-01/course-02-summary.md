# Summary

Desired state describes the managed configuration sufficient to establish the intended system behavior within its scope. Persistent business records are usually governed by separate data-management and recovery processes. External references, artifact identity and stable defaults determine how reproducible the configuration is. Generated status fields are evidence of implementation rather than automatically authoritative intent. Recreating configuration does not mean recreating every historical event or data value.
