# Summary

A declarative description states the intended operating condition rather than prescribing every action needed to reach it. Its usefulness depends on sufficient scope, stable references and interpretable inputs. The implementing agent still performs procedures and calls APIs. Hidden mutable defaults or unidentified external dependencies can make the same description produce different results. Declarative syntax alone does not establish reproducibility, safety or continued management.
