# Declarative Description

This section covers declarative Description. It develops declarative Descriptions And Implementation Independence through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Distinguish a desired-state description from an imperative procedure.
- Explain required scope and stable references in declarations.
- Reason about hidden defaults and external dependencies.
