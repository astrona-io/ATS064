# Welcome To The Course

This course is for learners preparing for the Certified GitOps Associate (CGOA) examination. It covers GitOps Terminology, worth 20% of the published curriculum. The examination tests knowledge through multiple-choice questions. The explanations in this course build the reasoning needed to choose an answer, and the hands-on labs let you see each term work on a real Kubernetes cluster.

At the end, you can explain and apply the terms Continuous, Declarative Description, Desired State, State Drift, State Reconciliation, GitOps Managed Software System, State Store, Feedback Loop and Rollback. You practise them with plain tools: a local Git repository as the state store, manifest files as the desired state, and `kubectl diff` and `kubectl apply` as the reconciliation step. Technical terms and acronyms are defined when they appear. Examples use a small set of example workloads named `scout`, `probe`, `shuttle` and `drifter`. The names identify workloads only and do not change the technical meaning.

Each section begins with an introduction and learning outcomes. Each module starts with a short map, continues with teaching parts, and ends with a summary. Each module has a playground, which is a clean Kubernetes cluster you can explore without any task, and a graded lab, which gives you a task and checks the result on the live cluster. Each section ends with a capstone lab and a knowledge check. A final knowledge check closes the course.

Read the examples carefully, identify which component does the work, and predict what changes when a condition changes. The practice questions are original and are not copied from the examination.
